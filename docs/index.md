# Python Package Template

A template for creating Python packages with UV, pytest, and Jupyter Book documentation

[Get started](getting_started.md) · [View on GitHub](https://github.com/opencitations/python-package-template)

## Features

- **UV dependency management**: fast, modern Python package management with UV.
- **Pytest testing**: pre-configured testing with pytest and coverage reports.
- **Jupyter Book documentation**: documentation site built with Jupyter Book.
- **Automated releases**: semantic versioning with automated releases to PyPI.

## Quick start

```bash
# Use this template on GitHub
# Then clone your new repository and run:
uv run python setup.py
```
